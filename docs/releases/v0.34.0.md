# ARM-Nator 0.34.0

Global Search now groups compatible provider copies while keeping remakes, conflicting identities, and playback choices separate. The workspace uses one search field and searches all indexed sources, including when the selected source is a portal.

Search cards and year sorting now use available catalogue year metadata and guarded title fallbacks. Display-only years do not change saved work identities or merge otherwise ambiguous titles.

Version language labels recognise explicit MULTI title tags and use MULTI categories as a fallback for untagged titles. Specific title languages such as EN or DE take priority over the category. Multi labels describe provider metadata; individual audio tracks are not inferred.

## Requirements and limitations

- Apple Silicon Mac running macOS 26.0 or later.
- The app uses ad-hoc signing and is not notarised.
- Portal category fallback requires the portal to supply a category name. Indexed Xtream results carry their saved category names.
- Missing or ambiguous year metadata can still appear as unknown. Provider availability and advertised audio languages are not guarantees of playable media or verified audio tracks.
- This is a scoped search release. Full provider setup/error, playback control/recovery, profile upgrade, and repeated-use/native-memory acceptance have not all been reverified for this release.
